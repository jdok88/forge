# 기술 트리 노드 카탈로그 (게임 내 한국어 표기 기준)

출처: `image/icons/` 게임 스크린샷 (2026-08-14 촬영, 한국어 클라이언트).
영문 Tech Tree Guide는 **대장간 트리 수치가 전부 2배로 잘못**되어 있으므로 이 문서가 정본이다.

## 브랜치 구성

기술 트리는 **4개 브랜치**다. 영문 가이드는 3개만 언급하며 S-Oil을 누락했다.

| 브랜치 | 노드 수 | 비고 |
|---|---|---|
| 대장간 | 10 | 전 노드 확인 완료 |
| 힘 | 20 | 구조 확인, 일부 노드 상세 미확인 |
| 스킬, 펫 & 기술 | 17 | 전 노드 확인 완료 |
| S-Oil | — | **클랜 기술. v1 스코프 제외** |

각 노드는 티어 I~V로 반복되며 티어마다 서브레벨 5단계 = 노드당 25단계.
표기 규칙: `<노드명> <로마숫자 티어>` (예: `제련 타이머 I`).

## 명명 규칙 관찰

- 노드 팝업은 `제목` / `설명 + (증가분)` 2줄 구조
- 현재 누적 효과는 검은색, 다음 레벨 증가분은 **초록색 괄호**로 표기
- 만렙 노드는 진행도 대신 `최대` 표시
- 다른 연구 진행 중이면 `다른 기술이 이미 연구 중입니다!` 경고

## 4. S-Oil — v1 제외

기술 트리 메인 화면에 4번째 브랜치로 존재하며 진행률 4.67%가 표시된다.
**클랜 기술**이며 아직 활용 시기가 아니라는 판단으로 **v1 스코프에서 제외**한다.
노드 구성·효과는 조사하지 않았다.

기술 트리 화면 상단에 재화가 2종 표시된다(빨간 물약 1.31k, 초록 시험관 32).
빨간 물약이 기술 업그레이드에 쓰이는 것은 확인됐다. 초록 시험관은 용도 미확인이며
S-Oil 관련 재화로 추정된다 — v1에서 다루지 않는다.

## 6. 게임 내 실측 검증 기록

계정이 순정이 아니라 `기술 연구 타이머 I` 5/5(+20%)와
`기술 노드 업그레이드 비용 I` 5/5(-10%)가 적용된 상태였다.
이 보정을 역산해 비용표(`tech cost and time_realreal.png`)를 3회 독립 검증했다.

| 노드 | 표시값 | 순정 기준값 | 검산 |
|---|---|---|---|
| 무기 숙련 I (0/5→1/5) | 4분 10초 / 27 | 300초 / 30 | 300÷1.2=250초 ✓ · 30×0.9=27 ✓ |
| 장비 판매 가격 I (1/5→2/5) | 8분 20초 / 38 | 600초 / 42 | 600÷1.2=500초 ✓ · 42×0.9=37.8→38 ✓ |
| 기술 연구 타이머 II (0/5→1/5) | 2시 13분 / 145 | 9,600초 / 161 | 9600÷1.2=8000초 ✓ · 161×0.9=144.9→145 ✓ |

→ 시간 `÷(1+속도)`, 비용 `×(1-할인)` 공식과 realreal 표가 모두 확정됐다.
`tech_real.png`(40/56/78… 계열)는 이 검증을 통과하지 못하므로 폐기한다.

## 7. 기타 확인 사항

- **펫 부화 슬롯은 4개.** 게임 화면에서 슬롯별 카운트다운 또는 `비어 있음` 표시
- 펫 소환 1회 = 알 100개
- 대장간 화면에 `대장간 레벨 N`과 별도 카운트다운이 존재. 업그레이드 타이머와 다른
  주기로 보이며 **정체 미확인** (자동 제련 주기 추정)
- 하단 탭 구성: `스킬` / `펫` / `기술 트리`
